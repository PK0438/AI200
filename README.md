# AI-200 Learning Repository

A practical Python-focused study repository for the AI-200 learning journey.
This repo follows the study flow outlined in the included `ai-200-16-week-plan.pdf` and is designed to help learners build strong fundamentals in Python while preparing for AI-200 certification topics.

## Overview

This repository is intended to help you:

- Learn Python from scratch
- Practice coding exercises in a structured way
- Build confidence with core programming concepts
- Follow a step-by-step 16-week learning roadmap
- Prepare for AI-200-style problem solving and practical application

## Why this repository?

The AI-200 path is best learned by doing. Instead of only reading theory, this repository focuses on:

- writing small Python programs
- understanding real coding concepts
- solving beginner-friendly exercises
- improving consistency and daily practice

## 16-week learning roadmap

This is the broad study flow reflected in the included plan:

### Week 1: Python foundations
- Install Python, VS Code, and setup tools
- Understand how Python programs run
- Learn `print()`, variables, and basic syntax

- Strings, integers, floats, booleans
- Type conversion
- Reading user input
- Basic formatting with f-strings

### Week 3: Control flow
- Comparison operators
- `if`, `elif`, and `else`
- Logical conditions and decision making

### Week 4: Loops and repetition
- `for` loops
- `while` loops
- Iterating through lists and data

### Week 5: Collections and data handling
- Lists, tuples, dictionaries
- Indexing and iteration
- Simple data processing

### Week 6: Functions and code organization
- Defining reusable functions
- Parameters and return values
- Breaking tasks into smaller units

### Week 7: Error handling and debugging
- `try` / `except`
- Handling invalid input
- Debugging common mistakes

### Week 8: File handling
- Reading and writing text files
- Working with CSV-style data
- Storing results

### Week 9: Working with modules and libraries
- Importing modules
- Using built-in Python libraries
- Understanding package structure

### Week 10: Data processing and JSON
- Parsing JSON data
- Handling structured input/output
- Real-world automation scenarios

### Week 11: Intro to AI and ML concepts in Python
- Data patterns
- Simple predictive logic
- Understanding model-ready data

### Week 12: Azure AI fundamentals using Python
- Working with common cloud AI concepts
- Simple Python integrations
- Intro to AI workloads and services

### Week 13: Prompt engineering and AI workflows
- Structured prompts
- Basic instruction design
- Using Python to interact with AI tools and APIs

### Week 14: Mini projects and hands-on labs
- Building small examples
- Combining learned concepts
- Practicing real-world tasks

### Week 15: Revision and assessment prep
- Review all key Python topics
- Practice questions
- Identify weak areas

### Week 16: Final review and exam readiness
- Consolidate knowledge
- Solve practice exercises
- Focus on confidence and consistency

## Getting started

### 1. Install Python

Download Python 3 from the official site:

- https://www.python.org/downloads/

### 2. Install VS Code

Install VS Code and add the Python extension:

- https://code.visualstudio.com/

### 3. Open the project folder

Open the repository folder in VS Code and run scripts like:

```bash
python ai200-python/day1.py
python ai200-python/day2.py
```
